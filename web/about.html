🚀 快速开始

文件上传：

📤 上传文件

要启用文件上传功能，请使用以下命令启动服务器：

sweb.exe -upload 或 sweb.exe --enable-upload

📤 上传功能已禁用

WebDAV服务：

🌐 访问WebDAV

可以在文件管理器中添加网络位置：http://localhost:8080/webdav

要启用WebDAV服务，请使用以下命令启动服务器：

sweb.exe -webdav 或 sweb.exe --enable-webdav

🌐 WebDAV服务已禁用

文件浏览：

📂 浏览文件

查看和下载web目录中的所有文件

要启用文件浏览功能，请使用以下命令启动服务器：

sweb.exe -files 或 sweb.exe --enable-files

📂 文件浏览已禁用

服务器信息：

  • 服务端口: 8080
  • 文件目录: ./web
  • 上传地址: /upload
  • 文件浏览: /files
  • WebDAV地址: /webdav
  • SOCKS5代理: localhost:1080
  • HTTP代理: localhost:10808

💡 使用说明

文件上传

  1. 上传文件：点击上方的"上传文件"按钮，选择要上传的文件
  2. 访问文件：上传成功后，文件将保存在web目录下，可以直接通过URL访问
  3. 管理文件：所有上传的文件都会显示在主页的文件列表中

WebDAV服务

  1. Windows：在文件资源管理器中，右键"此电脑" → "映射网络驱动器" → 输入WebDAV地址
  2. macOS：在Finder中，按Cmd+K → 输入WebDAV地址
  3. Linux：使用davfs2或其他WebDAV客户端挂载
  4. 移动设备：使用支持WebDAV的文件管理应用
  1. 启用功能：使用相应的命令行参数启动服务器
  2. 浏览文件：当前可以浏览和下载web目录中的现有文件
  3. 安全考虑：高级功能默认禁用，确保服务器安全

💡 Usage Instructions

File Upload

  1. Upload Files: Click the "Upload Files" button above and select files to upload
  2. Access Files: After successful upload, files are saved in the web directory and can be accessed directly via URL
  3. Manage Files: All uploaded files are displayed in the file list on the homepage

WebDAV Service

  1. Windows: In File Explorer, right-click "This PC" → "Map network drive" → Enter WebDAV address
  2. macOS: In Finder, press Cmd+K → Enter WebDAV address
  3. Linux: Use davfs2 or other WebDAV clients to mount
  4. Mobile Devices: Use file management apps that support WebDAV
  1. Enable Features: Start the server with corresponding command line parameters
  2. Browse Files: Currently you can browse and download existing files in the web directory
  3. Security Considerations: Advanced features are disabled by default to ensure server security
